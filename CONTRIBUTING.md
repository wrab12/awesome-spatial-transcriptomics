# Contributing

Thanks for helping improve this list! Suggestions are welcome through pull requests or issues.

## What belongs here

- Methods, tools and resources for **spatial transcriptomics** and the **single-cell** analyses it builds on.
- Tools should have public code and a paper (peer-reviewed, or a well-known preprint marked as such).
- Prefer tools that are maintained and actually used. A list that includes everything helps no one.

## How to add an entry

1. Find the right section. Tool tables are sorted by GitHub stars, which the badges update automatically.
2. Use the same format as the other rows in that section:

   ```markdown
   | [Name](https://github.com/owner/repo) | One-line description of what it does (≤ 20 words). | Python | [Nat Methods 2024](https://doi.org/...) | ![](https://img.shields.io/github/stars/owner/repo?style=flat-square&logo=github&label=) |
   ```

3. Check that every link works, and link the paper by its DOI (`https://doi.org/...`).
4. Add one tool per pull request, and in the description say briefly why it belongs on the list.

## Reporting problems

Dead links, archived repositories, wrong papers or better descriptions: please open an issue or a pull request.
